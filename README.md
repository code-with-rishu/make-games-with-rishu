# 🎮 games-with-rishu

A fantastic collection of fun, interactive, and lightweight web games built from scratch using HTML5, CSS3, and JavaScript. You can play all of these games directly inside your web browser!

## 🚀 Features
- **No Setup Required:** No need to download or install anything. Just open and play.
- **Responsive Design:** Optimized to run smoothly on both mobile devices and desktop screens.
- **Pure Frontend:** Built purely using frontend web technologies (HTML, CSS, and JS).

## 🛠️ How to Run Locally

If you want to play or experiment with these games on your computer, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate into the project folder:**
   ```bash
   cd games-with-rishu
   ```
3. **Launch a game:**
   - Open any game folder and double-click the `index.html` file.
   - For single-file games (like `PacMan Game.html`), simply double-click the file to open it directly in your browser.
